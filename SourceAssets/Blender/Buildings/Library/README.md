# Library — рабочая модель

Редактируемый источник: `Source/Library_Blockout.blend`.
Основной FBX: `Source/SM_Library_Blockout.fbx`.
Коллекция Blender: `BLD_Library`, корень: `Library_ROOT`.

В Unreal используется существующий ассет
`/Game/Art/Models/Buildings/Library/SM_Library_Blockout`.
Материалы находятся в `Library/Materials/`, будущие отдельные двери —
в `Library/Parts/`. Основной меш остаётся в корне `Library`.

## Порядок работы

1. Редактировать текущий `.blend`, сохраняя его структуру и материалы.
2. Для переноса сохранить исходник и запустить `Source/Scripts/export_fbx.py`
   в Blender в Object Mode. Он использует существующий экспортёр общежития:
   временные копии, метры, `-Y Forward`, `Z Up`, без сохранения исходной сцены.
3. В UE выбрать текущий `SM_Library_Blockout` и выполнить **Reimport**.
   Сохранять назначенные материалы и текущие настройки меша/коллизии.
   Не импортировать здание повторно как новый ассет.
4. Будущим самостоятельным створкам назначать `export_separately=True` и
   `unreal_asset=/Game/Art/Models/Buildings/Library/Parts/SM_Library_<Part>`.
   Весь состав створки должен иметь одинаковый путь; основной объект задаёт pivot,
   вспомогательным деталям назначается `export_support=True`.
   Для повторных экземпляров одного типа использовать `export_instance=True`.
   Экспортёр исключит части из корпуса и создаст отдельные FBX рядом с основным.
   Новые части импортировать отдельно в UE `Parts/`, без размещения на уровне.

`Source/model_config.json` хранит пути и настройки экспорта,
`Source/material_manifest.json` — текущие цвета Blender и соответствия материалов UE.
Диагностика экспорта: `Saved/BlenderToUE/library_export.json`.
