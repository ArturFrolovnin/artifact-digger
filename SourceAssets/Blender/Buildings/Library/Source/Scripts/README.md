# Library — scripts

`export_fbx.py` — короткий вход в проверенный экспортёр
`Buildings/Dormitory/Source/Scripts/export_fbx.py` с настройками библиотеки.
Открыть текущий `Library_Blockout.blend`, сохранить правки и запустить скрипт
в Object Mode. Исходная геометрия и `.blend` при экспорте не изменяются.

`import_ue.py` запускать в Python текущего Unreal Editor после экспорта:
`py "D:/UEProject/ArcheoDig/SourceAssets/Blender/Buildings/Library/Source/Scripts/import_ue.py"`
Он передаёт конфигурацию существующему FBX-импортёру RudyPawnshop, который
обновляет основной ассет по прежнему пути и импортирует створки в `Library/Parts/`.
Для воспроизводимых FBX-настроек Interchange временно отключается только на время
задачи; прежнее значение возвращается в `finally`. Масштаб импорта — 1.
Назначения материалов сохраняются по именам, новые материалы создаются из
манифеста вместо клетчатых заглушек. Стекло получает Translucent, светильники —
эмиссию. Материалы назначаются одним пакетом без перестройки меша на каждом слоте.
Корпус использует Complex As Simple, двери — одну простую коллизию и pivot петель.
Карты и акторы скрипт не изменяет и не сохраняет. Для повторного импорта
переиспользуются те же ассеты и материалы; новые копии здания не создаются.
Проверки/ошибки: `Saved/BlenderToUE/library_export.json`, `library_import.json`.
Экспортёр очищает вырожденные треугольники и UV только на временных копиях.
Полные пути и порядок работы описаны в `../../README.md`.
