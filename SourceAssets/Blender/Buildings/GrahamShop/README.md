# Магазин Грэма — рабочий исходник и импорт

Из Blender выполняется только экспорт FBX. Затем в Unreal открыть **Журнал
выходных данных**, выбрать **Cmd** и выполнить:

```text
py "D:/UEProject/ArcheoDig/SourceAssets/Blender/Buildings/GrahamShop/Source/finish_ue_import.py"
```

Ожидаемое сообщение: `GRAHAMSHOP_IMPORT_OK`. Этот способ проверен после изменения
входной лестницы. Ручной импорт через Interchange на текущем ассете завершался
ошибкой «Не удалось ничего импортировать»; скрипт использует FBX Factory.

## Актуальный перенос интерьера — 2026-11-13

Интерьер перенесён в существующий `SM_GrahamShop_Blockout`: 201987 треугольников.
Отдельная дверь: `Parts/SM_GrahamShop_Door_Entrance`, 908 треугольников в UE
(916 в FBX до удаления вырожденных граней импортёром),
Origin на петлях, один простой коллайдер. Дверь не входит в корпус.
Стекло `GRM_INT_ClearGlass`: Translucent, Opacity 0.12, Two Sided.
В Blender для просмотра прозрачности использовать Material Preview, не Solid.

Для следующего обновления выполнить `Source/export_fbx.py` в Blender, затем
`Source/finish_ue_import.py` в Python открытого Unreal Editor. Экспорт Blender
создаёт два FBX; материалы UE и папку Parts обрабатывает второй скрипт.
Восстановлены материалы после ручного импорта; все слоты имеют материалы проекта.
Старые сведения ниже описывают первоначальную подготовку до создания интерьера.

Единственная рабочая модель: `Source/GrahamShop_Blockout.blend`, как указано
в `models.json`. Дублирующий исходник удалён 2026-11-13 по просьбе пользователя
после сравнения 896 объектов, геометрии, UV, имён материалов, модификаторов
и трансформаций. Дальнейшие изменения выполнять в Blockout.

UE использует один собранный Static Mesh:
`/Game/Art/Models/Buildings/GrahamShop/SM_GrahamShop_Blockout`.
896 объектов Blender включают 3 источника света и корневой Empty;
экспортируются только Mesh, Curve и Font из `BLD_GrahamShop`.
В UE проверены 20 слотов материалов, 104871 треугольник, коллизия
`Use Complex Collision As Simple`, отсутствие простых оболочек и правильный
путь к существующему `Source/SM_GrahamShop_Blockout.fbx`.

## Экспорт и повторный импорт

1. Редактировать и сохранить `GrahamShop_Blockout.blend`.
2. В Blender, Object Mode, выполнить `Source/export_fbx.py`.
   Он использует существующий настроенный экспортёр Dormitory, как Library:
   временные копии, сохранение исходных нормалей, конвертация кривых/надписей
   только на копиях, UV для экспорта, метры, `-Y Forward`, `Z Up`, масштаб 1.
   Editable `.blend` скрипт не сохраняет. Камеры, свет и помощники исключаются.
3. В открытом Unreal Editor Python выполнить `Source/finish_ue_import.py`.
   Он передаёт конфигурацию существующему импортёру RudyPawnshop: обновление
   по точному прежнему пути, объединение мешей, сохранение назначений и порядка
   материалов, Nanite и комплексной коллизии, без автоматических оболочек.
   Несохранённые изменения целевого меша блокируют запуск.
   Обычный **Reimport** существующего меша также использует уже верный FBX.

`Source/model_config.json` задаёт пути и настройки.
`Source/material_manifest.json` хранит значения материалов Blender и соответствия
UE; существующие назначенные материалы имеют приоритет. При добавлении новых
материалов дополнить манифест перед импортом.
Для прозрачного витринного стекла Alpha Blender записана как `opacity`,
а `transmission: 1` включает Translucent при восстановлении материала импортёром;
исходное значение сохранено в `blender_transmission`. Существующий материал UE
не перенастраивается.

Независимые части пока не выделены (`parts: []`). Будущие подвижные части
экспортировать отдельно и регистрировать в `GrahamShop/Parts/` рядом с `Materials/`;
исключать их из корпуса. Настройка не создаёт двери, акторы или Blueprint.
Импортёр не размещает объекты и не сохраняет карты.

Проверочные отчёты находятся в `Saved/BlenderToUE/graham*`.
При подготовке настроек исходники, исходный FBX и геометрия UE не изменялись.
Проверочный экспорт в `Saved/` дал 104871 треугольник, 20 материалов и габариты,
совпадающие с UE лучше 0,1 см. Скрипт UE подготовлен на базе существующего
импортёра Руди; повторный импорт геометрии при этой настройке не запускался.
