# ArcheoDig

Прототип археологических раскопок и изменяемого грунта на Unreal Engine 5.8.

Текущий статус: реализация на Geometry Script / Dynamic Mesh сохранена как рабочий эталон. Следующий архитектурный эксперимент — небольшой ограниченный voxel `Dig Site` на Voxel Plugin Free Legacy.
