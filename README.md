# ArcheoDig

Прототип археологических раскопок и изменяемого грунта на Unreal Engine 5.8.

Текущий статус: реализация на Geometry Script / Dynamic Mesh сохранена как рабочий эталон. В Voxel Plugin Free Legacy прототипе `L_VoxelDig2` развивается Grass/Dirt material и освещение; следующий material-этап — Dirt Roughness.
