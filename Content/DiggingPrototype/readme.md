# DiggingPrototype
Открыть /Game/DiggingPrototype/L_DiggingTest, нажать Play.
Направить центр экрана на коричневую землю и нажать ЛКМ. Один щелчок удаляет один блок.
Движение, камера и прыжок — существующий игрок ThirdPerson без изменений.

## Assets
L_DiggingTest — тестовый уровень с существующим BP_ThirdPersonGameMode.
BP_DiggableGround — вся механика, включая генерацию земли и чтение ЛКМ.
SM_SoilBlock — отдельная копия стандартного куба с коллизией.
M_Soil — коричневый материал, roughness 0.95.

## Construction Script
SoilBlocks — Instanced Static Mesh Component: Movable, BlockAllDynamic, без симуляции физики.
Clear Instances очищает старую сетку.
Три For Loop: X=0..9, Y=0..9, Z=0..19.
Make Vector собирает индексы; Transform Location переводит их в центры блоков:
X=-450+100*X; Y=-450+100*Y; Z=-25-50*Z (см).
Make Transform задаёт масштаб (1,1,0.5); Add Instance добавляет блок.
Итого 2000 блоков 1x1x0.5 м, объём 10x10x10 м; верх Z=0, низ Z=-1000.
Для изменения сетки согласованно менять Last Index циклов, шаг и смещение в Make Transform, масштаб блока.

## Event Graph
Event Tick -> Get Player Controller (0) -> Was Input Key Just Pressed (LeftMouseButton) -> Branch.
На щелчок:
Get Player Camera Manager -> Get Camera Location и Get Camera Rotation -> Get Forward Vector.
End = Camera Location + Forward Vector * (800,800,800).
Line Trace By Channel (Visibility) от камеры до End: дальность 8 м от камеры.
Get Player Pawn -> Make Array -> Actors To Ignore исключает игрока.
Ignore Self обязательно FALSE: луч испускается из самого актора земли.
Branch проверяет попадание.
Break Hit Result -> Hit Component сравнивается с SoilBlocks -> Branch.
Hit Item -> Remove Instance удаляет попавший под луч блок вместе с коллизией.
Индекс не кешируется: при каждом щелчке новая трассировка.
Серые края и основание не копаются.

## Проверка Unreal MCP
Blueprint скомпилирован и сохранён.
В редакторе 2000 экземпляров, первый центр (-450,-450,-25), последний (450,450,-975).
В Play используются существующие ThirdPerson Character, Controller и GameMode.
Три щелчка через Slate MCP: 2000 -> 1999 -> 1998 -> 1997 экземпляров.
Удалены (-450,50,-25), (-350,50,-25), (-350,50,-75): подтверждено копание второго слоя.
Луч подтвердил дно на Z=-100.
Для проверки коллизии персонаж перемещён MCP над выемкой и сам опустился под действием гравитации.
Центр капсулы: Z=42.15 в яме 50 см, Z=-7.85 в яме 100 см.
Ещё два щелчка: 1995 экземпляров.
В LogScript нет Accessed None, Infinite loop, Runtime Error.
После Stop земля восстановилась. Это проверка основного сценария, не нагрузочное тестирование всей глубины.

## Ограничения
Форма блочная, удаление мгновенное, один блок на щелчок; удержание ЛКМ не повторяет действие.
Нет обрушений, сохранения ям и сетевой синхронизации. Новый Play восстанавливает землю.
Используется камера ThirdPerson, прицел не добавлен; целиться центром экрана.
Дальность измеряется от камеры, не от рук.
Ширина блока 1 м позволяет стандартной капсуле входить в яму. Для выхода заранее копать достаточно широкие ступени.
Для большого мира нужны чанки и оптимизация коллизии.
Путь к более плавному копанию: меньшие ячейки, удаление области вокруг Impact Point, затем поле плотности и построение гладкой поверхности с обновлением коллизии.

Существующие уровни и игровые assets при создании прототипа не редактировались.
