# Buildings — планирование зданий

Статус: **working model**.

Эта папка — источник истины по **размерам, этажности, внешнему стилю и blockout конкретных зданий** ArcheoDig.

## Почему вынесено отдельно

Во время первого city blockout стало понятно:

- по красивой карте сверху нельзя надёжно определить реальный масштаб;
- дороги и здания могут выглядеть нормально на схеме, но слишком большими в масштабе персонажа;
- финальную карту города рано фиксировать, пока неизвестны реальные размеры ключевых зданий;
- сначала нужно определить крупные здания, проверить их в UE5 ногами персонажа, и только потом собирать точный Town layout.

Поэтому текущий порядок:

```text
здание
→ функция
→ примерный footprint
→ этажность / высота
→ визуальный референс
→ blockout в UE5
→ проверка персонажем
→ корректировка
→ только после этого размещение на карте города
```

## Порядок проработки

Идём **от самых крупных к самым маленьким**:

1. Университет.
2. Общежитие.
3. Музей.
4. Библиотека.
5. Больница.
6. Автосалон + мастерская.
7. Администрация.
8. Кафе / бар.
9. Ломбард.
10. Магазин снаряжения.
11. Магазинчик у остановки.
12. Дом игрока / дом соседки / дома жителей.

Порядок можно менять, но большой Town layout не считать финальным, пока первые крупные здания не проверены.

## Статусы здания

Для каждого здания удобно использовать:

- **Concept** — понятна только функция.
- **Size test** — есть тестовый footprint / высота.
- **Visual approved** — внешний образ нравится.
- **UE blockout approved** — проверено в Unreal в масштабе персонажа.
- **Locked for Town layout** — размер можно использовать при финальной планировке города.

## Текущие важные выводы

- Unreal: **1 м = 100 Unreal Units**.
- Игрок по городу ходит пешком; город не проектируется под player driving.
- Ранний blockout показал, что широкие автомобильные дороги визуально раздувают город.
- Размеры зданий нужно определять не по изображению карты, а по функции и масштабу персонажа.
- Большое здание снаружи не обязано иметь полностью доступный интерьер.
- Интерьер моделируется только настолько, насколько он нужен gameplay.
- Для редактируемых зданий теперь используется Blender: **reference → Astra + Blender MCP → .blend → FBX → UE5 → прогулка / проверка масштаба → правка .blend**.
- Blender используется как мастерская отдельных зданий; город, дороги и gameplay по-прежнему собираются в UE5.
- Финальный визуальный результат оценивается в UE5: материалы и освещение Blender и Unreal не совпадают один в один.
