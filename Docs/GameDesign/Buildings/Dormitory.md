# Общежитие

Статус: **Visual direction approved / size test needed**.

## Роль

Стартовое жильё героя.

Дед, работающий при историческом университете, помогает герою получить комнату в общежитии.

## Этажность

Решение:

**3 этажа.**

Один этаж выглядел бы слишком маленьким для общежития, а большая многоэтажка не подходит масштабу компактного города.

Ориентир:

- 3 полноценных этажа;
- около **3–3.2 м** на этаж;
- стены около **9.5–10 м**;
- с крышей около **11–12 м**.

## Форма

После сравнения вариантов принято направление:

**общежитие должно быть компактным и почти квадратным.**

Не делать его длинным вытянутым бараком.

Рабочий первый тест:

- footprint примерно **22 × 22 м**;
- после сборки обязательно проверить персонажем;
- размер пока не считать locked.

## Визуальный стиль

Общежитие принадлежит тому же университетскому ансамблю:

- тёплый кирпич;
- светлая каменная отделка;
- тёмная крыша;
- центральный вход;
- регулярный ритм окон;
- аккуратная зелень.

Но по сравнению с университетом:

- меньше декоративных элементов;
- проще фасад;
- проще крыша;
- более функциональное ощущение.

## Интерьер

Не нужно строить реальную общагу целиком.

Минимально возможный доступный набор:

- входной холл;
- лестница / переход;
- коридор нужного этажа;
- комната героя;
- при необходимости общая кухня / небольшая бытовая зона.

Остальные комнаты могут существовать только визуально.

## Gameplay

Стартовая комната:

- ранний storage;
- сон / восстановление;
- стартовая точка до покупки собственного дома.

Позже собственный дом должен ощущаться заметным upgrade относительно комнаты в общаге.

## Следующий шаг

Собрать отдельный blockout общежития примерно **22 × 22 м / 3 этажа** по квадратному визуальному референсу и проверить:

- ощущение размера с улицы;
- масштаб окон / дверей;
- высоту этажей;
- сколько времени занимает обход корпуса;
- насколько оно визуально меньше университета.
