# Building References

Здесь сохранены текстовые ориентиры выбранных образов зданий. Фотореференсы и скриншоты удалены из проекта по запросу пользователя; автоматически добавлять их не нужно.

Выбранные визуальные ориентиры:

## University

Удачный reference:

- исторический кирпичный корпус;
- П-образная / составная форма;
- светлая каменная отделка;
- тёмная крыша;
- центральный парадный вход.

Пользователь отдельно отметил этот образ как подходящий для **университета**.

## Dormitory

Удачный reference:

- компактный почти квадратный корпус;
- 3 этажа;
- кирпич + светлый камень;
- тёмная крыша;
- центральный вход;
- более простой образ, чем у университета.
