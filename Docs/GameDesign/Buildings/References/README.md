# Building References

Здесь должны храниться **выбранные удачные изображения-референсы зданий**, а не все промежуточные генерации.

Текущие референсы, которые стоит сохранить:

## University

Удачный reference:

- исторический кирпичный корпус;
- П-образная / составная форма;
- светлая каменная отделка;
- тёмная крыша;
- центральный парадный вход.

Пользователь отдельно отметил этот образ как подходящий для **университета**.

## Dormitory

Удачный reference:

- компактный почти квадратный корпус;
- 3 этажа;
- кирпич + светлый камень;
- тёмная крыша;
- центральный вход;
- более простой образ, чем у университета.

## Astra UE result

Полезно хранить скрин UE prototype рядом с reference image, чтобы сравнивать:

```text
reference
→ blockout / procedural model
→ что реально получилось в UE
```

Это помогает оценивать, какие визуальные решения Astra хорошо переносит из изображения в уровень.

Файлы изображений можно добавлять в эту папку по мере утверждения конкретных референсов.
