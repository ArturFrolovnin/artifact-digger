# Building Style Guide

Статус: **working visual language**.

## Общий стиль

Основной визуальный reference игры — **Chop Chop Inc**.

Здания должны быть:

- стилизованными;
- хорошо читаемыми по силуэту;
- уютными;
- не фотореалистичными;
- достаточно детальными, чтобы город ощущался живым;
- без чрезмерной мелкой геометрии ради реализма.

Рабочее направление:

```text
полуреалистичная архитектура
+ немного усиленные формы
+ чистый читаемый силуэт
+ тёплые материалы
+ умеренная детализация
```

## Иерархия

Не все здания должны быть одинаково «богатыми».

### Landmark / ключевые

- университет;
- музей.

У них:

- более сложный силуэт;
- архитектурные акценты;
- выразительный вход;
- заметная крыша;
- больше декоративной отделки.

### Крупные функциональные

- общежитие;
- библиотека;
- больница;
- администрация.

Читаемые и характерные, но проще landmarks.

### Малые функциональные

- ломбард;
- магазин снаряжения;
- магазинчик у остановки;
- кафе / бар.

Индивидуальность достигается вывеской, формой входа, витриной, материалами и props, а не огромным размером.

### Жилые

- дом игрока;
- дом соседки;
- дома фоновых жителей.

Должны выглядеть уютно и отличаться деталями, но использовать повторяемую модульную базу.

## Университетская зона

Удачное найденное направление:

- красный / тёплый кирпич;
- светлый камень для углов, цоколя и обрамлений;
- тёмная сланцевая / черепичная крыша;
- деревянные двери;
- большие симметричные окна;
- мансардные окна;
- трубы;
- тёплый свет;
- ухоженная зелень;
- классические городские фонари.

Важно сохранять единый family look между:

- университетом;
- общежитием;
- библиотекой.

Но они не должны быть одинаковыми.

## Разница университет / общага

### Университет

Должен ощущаться главным зданием кампуса:

- более сложная форма;
- П-образный / составной корпус;
- парадный двор;
- колонны / фронтон;
- более богатая каменная отделка;
- мансардные окна и трубы;
- выраженный центральный вход.

### Общежитие

Должно быть:

- компактным;
- почти квадратным;
- 3-этажным;
- проще по композиции;
- с повторяемыми окнами;
- с центральным входом;
- в той же кирпично-каменной палитре;
- менее парадным.

То есть:

```text
университет = исторический landmark
общежитие = практичный корпус того же кампуса
```

## Производственный принцип

Reference image не является финальной моделью один в один.

Она задаёт:

- силуэт;
- пропорции;
- этажность;
- материалы;
- настроение;
- основные архитектурные детали.

После этого Astra / Unreal blockout проверяет, работает ли образ в настоящем масштабе.
