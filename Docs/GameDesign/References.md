# References

Статус: **working reference list**.

## Primary visual reference — Chop Chop Inc

Главный визуальный ориентир ArcheoDig.

Что нравится:

- стилизация без фотореализма;
- читаемые формы;
- компактный насыщенный мир;
- подходящий indie visual language.

Позже отдельно разобрать формы зданий, материалы, освещение, UI, окружение и пропорции. Не копировать стиль буквально.

## Secondary reference — PowerWash Simulator 2

Полезен прежде всего как reference для satisfying очистки и реставрации:

```text
грязный предмет
→ очистка
→ проявляется материал и форма
→ восстановленный красивый предмет
```

## Town scale reference — Internet Cafe Simulator 2

Reference по ощущению масштаба, а не по планировке.

Нужен компактный город примерно в этом духе, но потенциально в 1.5–2 раза насыщеннее по содержимому:

```text
маленькая территория
+ полезные точки
+ живые NPC
+ короткие пешие маршруты
```

Город не проектируется под player driving.
