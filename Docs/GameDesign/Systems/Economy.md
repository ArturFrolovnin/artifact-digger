# Economy

Статус: **working model**.

## Доход

### Раскопки
Главный источник денег: обычные ценные находки продаются.

### Реставрация
```text
грязный / повреждённый предмет
→ очистка
→ реставрация
→ выше цена
```

Домашнюю мастерскую позже можно автоматизировать через работников. Редкие / сюжетные предметы не продавать автоматически.

### Подработки
Вторичный доход и смена деятельности.

Основные места:

- кафе/бар;
- университет/библиотека;
- General Store;
- ломбард;
- администрация.

Интеллект влияет на доступность более квалифицированной работы и оплату.

### Музей
Небольшой passive income после восстановления. Не должен заменять активный заработок.

## Траты

- инструменты;
- одежда;
- expedition gear;
- расходники;
- еда / кофе;
- лицензии;
- подарки;
- дом и upgrades;
- мастерская;
- машина;
- музей;
- rescue / лечение;
- бар / развлечения;
- азартные игры.

## General Store

Через компактный catalogue UI:

- подарки;
- еда;
- напитки;
- бытовые мелочи;
- декор;
- сезонные вещи.

## Принцип

```text
раскопки → главный доход
реставрация → повышает ценность loot
подработки → страховочный доход
музей → небольшой passive income
```

Крупные покупки требуют активной игры.
