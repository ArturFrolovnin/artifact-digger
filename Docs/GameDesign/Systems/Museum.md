# Museum

Статус: **working model**.

## Роль

После пожара задача героя и деда:

```text
раскопки
→ находки
→ коллекция
→ восстановление
→ оживление музея
```

Исторически значимые предметы идут в музей. Обычные ценности могут продаваться / реставрироваться.

Если музейный предмет ошибочно продан Руди, его можно выкупить обратно.

## Визуальная progression

```text
пустые / повреждённые помещения
→ первые экспонаты
→ витрины
→ новые зоны
→ посетители
→ живой музей
```

Музей — визуальный progress bar игры.

## Passive income

Лучше коллекция → больше посетителей → выше выручка → небольшой пассивный доход.

Потенциальные факторы:

- количество экспонатов;
- редкость;
- разнообразие;
- открытые залы;
- состояние музея;
- знаменитые находки;
- репутация.

Доход — приятный бонус, а не замена раскопкам. Может начисляться раз в игровой день.
