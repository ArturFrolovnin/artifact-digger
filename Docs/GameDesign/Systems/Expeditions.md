# Expeditions

Статус: **working model**.

## Loop

```text
Town
→ подготовка
→ Dig Site
→ раскопки
→ loot
→ Town
→ музей / ломбард / мастерская
```

## Loadout

Перед поездкой игрок выбирает ограниченный набор:

- инструменты;
- одежду;
- еду;
- кофе;
- фонарь;
- расходники;
- оборудование.

## Автобус

Стартовый способ travel. Может тратить stamina / ресурс.

## Машина

**Не управляется вручную.**

Это mobile expedition storage:

- больший багажник;
- больше loadout;
- меньше travel stamina;
- потенциальный доступ к некоторым участкам.

На Dig Site машина может быть статичным объектом с доступом к багажнику.

## Телефон

In-world UI:

- inventory;
- messages;
- calls;
- contacts;
- quests;
- notes;
- news;
- Dig Sites;
- museum;
- Emergency.

## Rescue / Hospital

```text
fail / застревание
→ спасатели
→ больница
→ восстановление
→ денежный счёт
→ продолжение
```

**Предметы не теряются.** Спасатели сохраняют инструменты, loot, артефакты и весь inventory.

Стоимость rescue позже зависит от места / сложности / происшествия.

Emergency — также безопасный выход из terrain edge cases.

## Лицензии

```text
открыт новый Dig Site
→ администрация
→ лицензия
→ экспедиция
```

Точный баланс лицензий позже.
