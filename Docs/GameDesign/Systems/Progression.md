# Character Progression

Статус: **working model**.

## Принцип

Не тяжёлое RPG-дерево, а progression через реальные действия.

```text
игрок делает действие
→ накапливает опыт
→ характеристика развивается
```

Можно учитывать:

- количество копков;
- объём грунта;
- экспедиции;
- инструменты;
- найденные / оценённые предметы.

## Интеллект

Развивается через исторический университет / библиотеку.

Влияет на:

- оценку стоимости;
- редкость;
- торг;
- dialogue options;
- отношения;
- квалифицированные подработки;
- оплату;
- исторические сведения.

Учёба: простой выбор + transition + игровое время, без симулятора чтения.

## Физическая форма

Спортзал + сама работа.

Возможные эффекты:

- stamina;
- выносливость;
- сила;
- восстановление;
- эффективность тяжёлых инструментов.

## Жильё

```text
общага
→ свой дом
→ кровать
→ storage
→ мастерская
→ машина / гараж
→ upgrades
```

Сон восстанавливает stamina; качество кровати может давать бонусы.

## Парикмахерская

Cosmetic progression через простую transition.

## Scope

Не делать отдельную mini-game для каждой бытовой активности.
