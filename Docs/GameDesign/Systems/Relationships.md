# Relationships

Статус: **early working model**.

Отношения должны ощущаться через поведение NPC, а не только число Friendship.

Возможные эффекты:

- тон диалогов;
- новые реплики;
- поручения;
- помощь;
- личные истории;
- романтика.

## Подарки

Основной источник простых подарков — General Store.

Нужны предпочтения NPC и diminishing returns, чтобы нельзя было спамить один дешёвый подарок.

## Интеллект

Может открывать дополнительные dialogue options, усиливать торг и помогать в социальных ситуациях.

## Романтика

### Соседка
Основная сюжетная романтическая линия:

- живёт рядом;
- приятная;
- доброжелательная;
- спокойная;
- работает удалённо;
- гуляет с собакой.

### Девушка из автосалона
Ещё одна возможная линия:

- уверенная;
- кокетливая;
- разбирается в машинах;
- объясняет transport progression;
- слегка подкалывает героя.
