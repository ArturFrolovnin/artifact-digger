## Visual / Style References

### Main reference — Chop Chop Inc

**Chop Chop Inc** — основной визуальный референс для ArcheoDig на текущем этапе.

Что фиксируем сейчас:

- пользователю очень нравится общая стилистика игры;
- стиль хорошо воспринимается как направление для ArcheoDig;
- использовать её как **главный reference point** при дальнейших обсуждениях визуального языка игры;
- конкретные элементы, которые будем заимствовать как ориентир (форма объектов, материалы, освещение, UI, окружение и т.д.), нужно разобрать отдельно позже.

### Secondary reference — PowerWash Simulator 2

**PowerWash Simulator 2** также хорошо подходит как дополнительный визуальный/атмосферный референс.

Пока фиксируем его как **secondary reference**, а не как главный.
