# Dig Sites

Статус: **working model**.

Город — hub, крупные раскопы — отдельные levels.

```text
Town
→ подготовка
→ travel
→ Dig Site
→ раскопки
→ возвращение
→ Town
```

Это позволяет делать разные биомы, грунты, находки и hazards, не превращая весь мир в voxel terrain.

## Открытие

```text
сюжет / дед / слух / исследование
→ найдена потенциальная точка
→ при необходимости лицензия
→ Dig Site доступен
```

Администрация оформляет доступ, но не заменяет discovery.

## Опасности

- животные / волки;
- падение;
- обвал;
- истощение;
- плохая подготовка;
- застревание в terrain.

Животные — environmental hazard, не основа combat.

## Исчерпаемость

Игрок может понять, что текущий участок почти полностью исследован и пора двигаться к новому.
