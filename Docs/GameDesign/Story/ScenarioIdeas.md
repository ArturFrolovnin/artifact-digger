# Scenario Ideas / Open Questions

Сюда складываются новые сюжетные гипотезы, которые ещё не стали частью текущей модели.

## Открытые вопросы

- название города;
- страна / регион;
- точный возраст и специализация героя;
- имя, возраст и полная история деда;
- обстоятельства пожара;
- связан ли пожар с главной тайной;
- цивилизация / эпоха артефакта;
- внешний вид артефакта;
- точный принцип его способности;
- точная романтическая финальная развилка;
- количество романтических линий;
- структура актов / глав;
- цепочка сюжетных находок.

Когда идея оформляется, переносить её в тематический документ.
